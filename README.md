## 📌 Sobre o Projeto

O **Sorteador de Jogos** é um projeto desenvolvido com o objetivo de tornar a escolha de um jogo mais simples, rápida e divertida. 🎮✨

Sabe aquele momento em que você abre sua biblioteca de jogos, olha para várias opções e pensa:

> **"Tem tanto jogo e eu não sei qual jogar..."** 😭

Foi pensando nisso que criamos o **Sorteador de Jogos**!

O sistema conta com **dois modos diferentes de sorteio**, oferecendo ao jogador liberdade para escolher suas próprias opções ou simplesmente deixar que o sistema decida por ele.

---

# 🎲 Modos de Sorteio

## 👤 1. Sorteio Personalizado

No **Sorteio Personalizado**, o jogador possui controle sobre quais jogos poderão ser sorteados.

O usuário pode selecionar os jogos desejados e, após confirmar sua escolha, o sistema realiza um sorteio aleatório entre eles.
