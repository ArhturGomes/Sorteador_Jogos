# 📖 Sobre o Projeto

O **Sorteador de Jogos** é uma aplicação desenvolvida com o propósito de solucionar um problema bastante comum entre jogadores: **a dificuldade de escolher qual jogo jogar**. 🎮

Com uma grande quantidade de jogos disponíveis atualmente, muitas vezes passamos mais tempo escolhendo o que jogar do que realmente jogando.

> 😵‍💫 "Tenho vários jogos, mas não faço ideia de qual jogar."

Pensando nisso, nossa equipe desenvolveu uma solução simples, prática e divertida: **deixar a sorte escolher! 🎲**

O projeto disponibiliza **dois diferentes sistemas de sorteio**:

- 👤 **Sorteio Personalizado**
- 🤖 **Sorteio Aleatório**

Cada modo possui uma proposta diferente, permitindo que o usuário tenha liberdade para escolher suas opções ou simplesmente entregue a decisão ao sistema.

# 🎯 Objetivo Geral

Desenvolver uma aplicação capaz de realizar sorteios de jogos de maneira simples, rápida e intuitiva, oferecendo ao usuário diferentes formas de definir quais jogos poderão ser selecionados.

Além de proporcionar uma experiência divertida, o projeto também tem como objetivo colocar em prática conhecimentos relacionados à:

- 💻 Programação;
- 🧠 Lógica computacional;
- 🎲 Geração de valores aleatórios;
- 🖥️ Desenvolvimento de interfaces;
- 🗂️ Organização de dados;
- 🧪 Testes e validação;
- 🤝 Trabalho em equipe;
- 🚀 Desenvolvimento de projetos.

---

# 🎯 Objetivos Específicos

O projeto busca:

- 🎮 Criar um sistema funcional de sorteio de jogos;
- 👤 Permitir que o usuário defina quais jogos participarão do sorteio;
- 🤖 Disponibilizar um modo totalmente automático;
- 🎲 Garantir que a escolha seja realizada de forma aleatória;
- 🏆 Apresentar claramente o resultado do sorteio;
- 🔄 Permitir que novos sorteios sejam realizados;
- 🖥️ Desenvolver uma interface simples e intuitiva;
- 🚀 Criar uma base que possa receber novas funcionalidades no futuro.

# 🎲 Modos de Sorteio

## 👤 Sorteio Personalizado

O **Sorteio Personalizado** permite que o próprio jogador determine quais jogos estarão disponíveis para o sorteio.

Esse modo oferece maior controle ao usuário, permitindo criar uma seleção específica de jogos.

### ⚙️ Como funciona?

1. 🎮 O usuário visualiza os jogos disponíveis.
2. ☑️ Seleciona os jogos que deseja incluir.
3. 📋 O sistema cria uma lista com as opções selecionadas.
4. 🎲 O sistema realiza o sorteio.
5. 🏆 O jogo escolhido é apresentado ao usuário.
6. 🎮 O jogador pode iniciar sua próxima aventura!
